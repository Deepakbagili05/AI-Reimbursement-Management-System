# AI-Enhanced Reimbursement Management System

## Project Overview

This project automates the reimbursement management process using Machine Learning and AI.

Employees can:

* Register
* Login
* Submit reimbursement requests
* View reimbursement history

Administrators can:

* Approve requests
* Reject requests

The system also includes:

* Random Forest based reimbursement prediction
* AI-generated reimbursement summaries
